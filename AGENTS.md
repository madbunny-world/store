# MADBUNNY storefront

Ecommerce storefront for a character-IP drop brand. Sources of truth:
- `sources/MADBUNNY_Build_Spec.md` — **how it's built.** Read §10 Decision Log before "fixing" anything: several things look like bugs and are intentional (serial always fails, stock counter usually hidden, prices have no cents).
- `Madbunny_Brand Deck_v2.pdf` — **how it looks**, plus `/about` copy.
- Build plan: `~/.claude/plans/this-folder-has-all-validated-pretzel.md`.

**Stack:** Next.js 16 (App Router) + TS · Tailwind **v4** (tokens in `@theme` in `app/globals.css`, no `tailwind.config`) · lucide-react · Shopify Storefront API (reads + cart only; **never build checkout**) · Geist Mono via `next/font` + Helvetica Neue body · Splatink display type as inline SVG paths only — generated by `scripts/generate-splatink.py` (fontTools; opentype.js emits NaN for this CFF font) from Gia's local commercial `.otf`, which is never committed or served. Splatink commercial desktop license is held (purchased 2026-07).

**Palette (Deck v2, the only one):** Black `#151312` · Mad Red `#FF402B` · Bunny White `#FFF8F8` · Gun Metal `#4D5257` · Bunny Pink `#FFBFB4`.
**Design-pass overrides (Gia, 2026-07 — do not "fix" back):** page backgrounds are pure `#FFFFFF` (supersedes the deck's "never pure white" for backgrounds); card/image wells are `--color-card #f4f4f4`; no pink surfaces. Nav is one centered group with the bunny mark in the middle, Instagram pinned right; cart is a floating right-edge bubble (`FloatingCart`, hidden on `/`); footer centered. Home bunny links to `/collectibles`. Favicon = `app/icon.svg` (real brand mark, also used in `BunnyMark`).

**Voice:** short declarative sentences, no exclamation marks, no emojis, dry. Applies to every string incl. errors and alt text. Serial rejection is exactly `Not a valid serial.`

**Data:** `lib/shopify/queries.ts` fetches full detail for every product in a collection (prefetch-all — the catalog is tiny, modals open with no spinner). Money via `lib/money.ts` (no cents). Zone clocks via `lib/time.ts` (offset derived from `Intl`, never hardcoded).

**Env:** copy `.env.local.example` → `.env.local`. Dev-only Shopify check: `GET /api/debug/shopify`.

## Live store reality (differs from the build spec — reconciled with Gia)

The actual Shopify store (`madbunny-2644`) diverges from spec §5; the code adapts to the store, which is source of truth:
- **No `collectibles`/`apparel` collections.** Catalog is organized by **tags**: `Collectible toys`, `Fine art collection`, `Apparel`. Pages split `getAllProducts()` by tag via `lib/catalog.ts`. Do not query by collection handle.
- **Toy colorways are 3 separate products** (Bunny Black / Mad Red / Gun Metal), each a single default variant — not one product with a Color option. So "variant-per-card" (spec D-08) doesn't apply; each is its own card.
- **Fine art = inquiry-only** (Gia's call): tag `Fine art collection` → "Inquire" mailto, no cart, no "Sold" badge even at qty 0. All 6 paintings are currently qty 0.
- **Apparel is NOT empty** — 3 real tees with size/color variants (build Phase 3 for real).
- **Handles contain `®`** (e.g. `madbunny®-hello-world-100-mad-red`), which breaks Next's intercepting-route matcher and makes un-shareable URLs. We route on `slugify(handle)` (`lib/slug.ts`) and resolve back via `getProductBySlug`. Keep this.
- 🔴 **All `custom.*` metafields return null** via Storefront API (year, dimensions, edition, medium, tier). Either unset or missing "Storefront API access: read". Modal detail is graceful-empty until Gia fixes this in Admin — then it fills in with no code change.
